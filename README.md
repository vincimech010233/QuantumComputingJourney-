# Quantum Computing Journey

[Español](README.es.md)

A study repository of quantum-computing notebooks and small simulations using Qiskit, PennyLane, Cirq, QuTiP, ProjectQ, and pure Python.

## Topics

- Qubits, gates, measurement, and entanglement
- Grover, Bernstein–Vazirani, QAOA, VQE, and Shor-related exercises
- Noise simulation and backend sampling
- Quantum machine-learning experiments
- IBM Quantum Challenge and Qiskit Global Summer School labs

## Reproducibility

The notebooks were created at different times and may require different library versions or hosted services. Use a separate virtual environment for each coherent group and replace placeholder credentials through environment variables when a remote backend is genuinely required.

## Limitations

This is a learning record, not a benchmark suite or claim of quantum advantage. Some notebooks originate from public courses or challenges; their original instructions and terms remain applicable.

## Security

Do not store IBM Quantum or other provider tokens in notebooks. Clear notebook outputs and metadata before committing sensitive sessions.
